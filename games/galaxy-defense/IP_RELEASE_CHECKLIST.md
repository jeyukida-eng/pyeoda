# 《은하방어선》 권리 점검 및 Play 출시 체크리스트

작업일: 2026-10-16. 이 문서는 법률 의견이 아닌 개발 내부 점검 기록입니다.

## 1. 구현한 차별화
- 게임 표시 명칭: 우주방어전 / 별자리 잇기 / 별빛대작전 (타사 게임 이름 미사용)
- 우주방어전: 영웅 고유 발사체 + 회전 결정형 적 + 성운 궤도 코어 보스
- 별자리 잇기: 낙하 블록/테트로미노 전면 제거. 4~9개의 순서가 있는 별을 드래그/터치하여 연결, 움직이는 별과 제한 시간, 영웅별 능력으로 진행하는 터치 퍼즐
- 별빛대작전: 영웅별 황금화살·몽돌·꽃잎 빛 표식 연쇄 공명, 원형 몬스터/갇힌 적 얼굴 표현을 기하학적 결정체 및 부호로 교체
- UI/PWA 제목과 주요 설명에서 과거 유명 게임 표기를 제거
- 모바일 뷰: 전투 구역 기준 세로 표시 범위 확장 (화면 잘림 방지 목적)

## 2. 실제 출시 이전에 확인 필요 (미완료)
- [ ] **인물 이미지 3종**: 제작 파일, 생성/수정 이력, 제3자 이미지 무단 사용 여부
- [ ] **PWA/스토어 아이콘**: 기존 PNG 32/180/192/512의 제작 과정과 권리; 다른 게임 로고와 유사성
- [ ] **사운드·폰트·외부 이미지**: 출처와 라이선스 증빙 확보
- [ ] 스토어 제목 및 각 게임 모드 명칭의 국내외 상표 검색(KIPRIS 포함)
- [ ] 실제 주요 경쟁작과 화면/플레이를 나란히 비교하고 독립 디자인 최종 검수
- [ ] 모바일(아이폰/안드로이드)에서 세 모드 실기기 조작 및 보스/상단 적 표시 확인
- [ ] 별자리 잇기: 드래그와 개별 터치, 회전/작은 화면 크기, 일시정지/나가기, 기록 저장 검증
- [ ] Google Play 개인정보처리방침 및 데이터 안전 양식 작성; 원격 순위 서버 사용 검토
- [ ] Android AAB 재빌드·서명 및 비공개 테스트
- [ ] 법률 전문가 검토가 필요한 고위험 유사성이 없는지 검토

## 3. 정책
Google Play 지적 재산권 정책은 타인의 상표·저작권·특허·영업비밀 침해를 금지합니다. 변형한 저작물도 허가 없는 사용이라면 여전히 문제가 될 수 있으므로, 이름 바꾸기만으로 충분하다고 주장하지 않습니다.

공식 정책: https://support.google.com/googleplay/android-developer/answer/9888072?hl=ko
