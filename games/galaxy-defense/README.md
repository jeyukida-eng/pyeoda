# 은하 방어선 · HERO EVOLUTION

부이, 몽돌이, 소랑이 중 한 캐릭터를 골라 플레이하는 모바일 우주 슈팅게임입니다.

## 🎮 바로 플레이
**[게임 실행하기 (iPhone Safari / Android)](https://jeyukida-eng.github.io/pyeoda/games/galaxy-defense/)**

아이폰에서는 `index.html` 파일을 다운로드해 미리보기로 열지 말고 **위 HTTPS 주소를 Safari에서 여세요.** 파일 앱 미리보기나 일부 앱 내 뷰어는 JavaScript 게임 조작이 제한될 수 있습니다.

## 조작
- 모바일: 손가락 좌우 이동, 자동 발사, 오른쪽 아래 ULTIMATE
- PC: ← / → (또는 A/D), B 궁극기, P 일시정지
- 종료: 오른쪽 위 Ⅱ → 처음으로

## 게임 특징
- 부이: 황금 화살 미사일
- 몽돌이: 몽돌 관통 공격
- 소랑이: 꽃잎 유도 공격
- 5웨이브마다 보스, 웨이브별 난이도 증가 및 무기 강화
